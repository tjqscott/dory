# Dory v3

The v3 design, and what is still open. When a row changes, update this page in the same PR as the code.

## Goals

- **Keep v1's point:** give the model the memory it lacks, in plain files, with no tooling and any model.
- **Enforce, don't ask:** tooling holds each discipline. Writers append, a separate step curates, and a guard rejects bad writes so the model retries.
- **Reach the people who star repos:** users of Claude Code, Codex and hosted chats.

## Decisions

| Decision | Why | Where |
| --- | --- | --- |
| Two editions in one repo | the browser has no filesystem and a coding host has one, and one spec that half-applies gets half-ignored | `browser/`, `code/` |
| Directives live only in `AGENTS.md` | one home; Codex reads the filename natively | `AGENTS.md` |
| Token Gating deleted | a hosted model can't see its own token count; the page measures the paste instead | `AGENTS.md`, `browser/` |
| Browser memory is posts, superseded with `replaces` and never edited | small models can append reliably but can't edit safely | `browser/` |
| The page assigns ids and rejects malformed posts with a message to paste back | a guard beats trusting free text | `browser/` |
| `initialise.py` deleted; tree and probe are read in the page | refreshable, and no install | `browser/` |
| `CHANGELOG.md` and `history/` replaced by the `decisions` and `tried` pages | a flat log degrades to noise nobody rereads | `AGENTS.md` IV and V |
| Code memory is a strict-tree wiki, edited in place with git as history | a capable agent can edit, and git keeps the old text | `AGENTS.md` V, `code/` |
| A findings ledger (`tried.md`) | three repos grew one unprompted, and it stops experiments being re-run | `code/wiki-template/` |
| Usage-aware long runs: soft at 90%, hard at 95%, CPU jobs across the reset | the limit is the constraint on all-day runs | `AGENTS.md` VI, `code/skills/loop/` |
| Rate limits reach hooks through the statusline | only the statusline receives them | `code/scripts/usage_statusline.py` |
| No LLM Wiki credit | Dory's names predate it | — |
